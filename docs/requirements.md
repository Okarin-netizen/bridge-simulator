# 要求の一覧（かけはしラボ）

IPA「AI時代の要求管理ハンドブック」の考え方で、この制作物の要求をまとめた台帳です。
2026年11月23日の点検で書き起こしたものなので、状態はすべて「候補」です。
すでに実装されているものも、内容を確かめて「承認」にするまでは「候補」のままにしています。

## 目的

- 何のため：橋を組みながら、トラス・座屈・ラーメン構造・材料の使い分けを体験して学ぶ
- 誰のため：技術科の生徒（授業1〜2コマ）と、授業をする先生
- 成功の目安：1〜2コマで 4-1 まで進み、トラスとラーメンの違いを自分の言葉で書ける

### 全制作物に共通の要求

どの制作物にも当てはめる要求です。この制作物でまだ満たしていないものは、上の一覧か下の指摘に入れています。

| ID | 要求 |
|---|---|
| COM-01 | 画面とREADMEに、作者・版・更新日・ライセンス・連絡先を書く |
| COM-02 | 対象（学年・単元・場面）と目的を、READMEと画面に書く |
| COM-03 | 端末に残るもの・外に送るものと、その消し方を書く |
| COM-04 | ライブラリはCDNから読まず同梱する（学校のネットワークで止められても動く） |
| COM-05 | 生徒のデータを外に送るときは、送る項目・送り先・公開範囲・保存期間を決めてから送る |
| COM-06 | 点検やレビューの指摘は、この台帳に載せて扱いを決める |
| COM-07 | 授業や校務で使ったら、日付・場面・版・結果を記録する |

## 書き方のきまり

- 状態は「候補 → 承認 → 実装中 → 検証済み」と進めます。やめたものは「見送り」、決めかねているものは「保留」にします。
- 要求を変えたら、変更の履歴に日付と理由を書きます。IDは使い回しません。
- 受入条件を確かめたら、結果の欄に日付と結果を書きます。
