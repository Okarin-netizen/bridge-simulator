# かけはしラボ（ブリッジシミュレーター）

中学生が、谷に橋をかけて車を走らせながら「構造」と「材料」を学ぶブラウザ教材です。
トラス構造とラーメン構造のちがい、引張・圧縮・座屈、材料と断面による強さのちがいを、
試して・こわして・直すことで体験できます。

## 動かし方

```bash
npm install
npm run dev      # 開発用サーバー（http://localhost:5173）
npm test         # 構造計算のテスト
npm run build    # 公開用のファイルを dist/ に作る
```

## しくみ

橋の計算は、ゲーム用の物理エンジンではなく構造力学の計算（直接剛性法）で行っています。
画面に出る力の値は、教科書の例題と同じ答えになることをテストで確かめています。

| ファイル | 役割 |
| --- | --- |
| `src/engine/analyze.ts` | 骨組みの解析。ピン接合の端は曲げを伝えない（トラス）、剛接合は曲げも伝える（ラーメン） |
| `src/engine/crossing.ts` | 車を少しずつ進めて、位置ごとに橋を計算する走行試験 |
| `src/engine/materials.ts` | 材料（木材・鋼材・アルミ合金）と断面（角材・パイプ・H形）の値 |
| `src/game/` | ステージ、組み立て中の橋、結果の説明文 |
| `src/ui/` | キャンバスへの描画 |

部材の壊れ方は 4 種類で判定します。

- 引張：引っぱる力 ÷ 断面積 が材料の強さをこえる
- 圧縮：押す力 ÷ 断面積 が材料の強さをこえる
- 座屈：押す力がオイラーの座屈荷重 π²EI/L² をこえる
- 曲げ：剛接合の部材で、曲げによる応力が加わって強さをこえる
