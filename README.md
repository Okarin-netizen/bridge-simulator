# かけはしラボ（ブリッジシミュレーター）

中学生が、谷に橋をかけて車を走らせながら「構造」と「材料」を学ぶブラウザ教材です。
トラス構造とラーメン構造のちがい、引張・圧縮・座屈、材料と断面による強さのちがいを、
試して・こわして・直すことで体験できます。

## 公開ページ

https://okarin-netizen.github.io/bridge-simulator/

main ブランチに変更が入ると、GitHub Actions が自動でテスト・ビルドして公開します。

一度ページを開いた端末では、ネットにつながっていなくても使えます（`public/sw.js`）。
授業の前に、各 Chromebook で一度開いておくと安心です。ネットにつながっているときは、毎回いちばん新しい版を読み込みます。

## ステージ

授業 1〜2 コマで取り組める分量として、9 ステージと実験モードがあります。授業の流れ・発問の例・ステージごとの解説は先生用ページ（`teacher.html`、ステージ選択画面の右上から開けます）にまとめています。

| ステージ | 学ぶこと |
| --- | --- |
| 1-1, 1-2 | 部材を組んで谷をわたす操作 |
| 2-1, 2-2 | 三角形（トラス）はくずれにくい。予算の中で工夫する |
| 2-3 | トラスは道路の下にも組める。押される部材と引っぱられる部材が入れかわる |
| 3-1 | 押される部材は座屈する。断面を変えて強くする |
| 3-2 | 斜材なしでも、剛接合（ラーメン構造）ならくずれない |
| 3-3 | 材料の使い分け。強いけれど高い鋼材を、押される部材にだけ使う |
| 4-1 | これまでの工夫を組み合わせるチャレンジ |

評価は星 3 つ（わたり切る・予算内・負担率 70% 以下）で、記録は端末のブラウザに保存されます。
どのステージにも星 3 つを取れる答えがあることは `tests/stages.test.ts` で確かめています。

配布用の PDF として、A4 両面 1 枚のかんたん説明書（生徒用、`public/docs/quick-guide.pdf`）、操作説明書（生徒用、`public/docs/manual.pdf`）と全ステージの模範解答（先生用、`public/docs/answers.pdf`）があり、先生用ページから開けます。模範解答の橋は、テストと同じ形をゲーム画面で実際に組んで試験し、星 3 つになることを確かめたものです。ステージを変えたときは PDF も作り直してください。

## しくみ

橋の計算は、ゲーム用の物理エンジンではなく構造力学の計算（直接剛性法）で行っています。
画面に出る力の値は、教科書の例題と同じ答えになることをテストで確かめています。

| ファイル | 役割 |
| --- | --- |
| `src/engine/analyze.ts` | 骨組みの解析。ピン接合の端は曲げを伝えない（トラス）、剛接合は曲げも伝える（ラーメン） |
| `src/engine/crossing.ts` | 車を少しずつ進めて、位置ごとに橋を計算する走行試験 |
| `src/engine/materials.ts` | 材料（木材・鋼材・アルミ合金）と断面（角材・パイプ・H形）の値 |
| `src/game/` | ステージ、組み立て中の橋、結果の説明文 |
| `src/ui/` | キャンバスへの描画 |

部材の壊れ方は 4 種類で判定します。

- 引張：引っぱる力 ÷ 断面積 が材料の強さをこえる
- 圧縮：押す力 ÷ 断面積 が材料の強さをこえる
- 座屈：押す力がオイラーの座屈荷重 π²EI/L² をこえる
- 曲げ：剛接合の部材で、曲げによる応力が加わって強さをこえる
